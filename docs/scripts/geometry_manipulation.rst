Geometry Merging (:py:mod:`scripts.geometry_manipulation`)
==============================================================

This page details the geometry merging procedure. The functions in this module are used to group geometries
by category based on their attribute tags. Once they are categorized and grouped by category, all geometries that
physically overlap with each other are merged into one large geometric shape. The process is repeated for all categories.
