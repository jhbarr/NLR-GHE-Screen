MS Footprint Cross Validation (:py:mod:`scripts.ms_cross_validation`)
=====================================================================

This page details the operations of the MS footprint cross validation functions. This module
is designed to query the MS Footprint database given the user defined bounding box area. 
It then scrapes all buildings from that area and cross validates them with the data scraped from OpenStreetMap
