OpenTopography Reference
========================
An open access high resolution topographic database funded by the US National Science Foundation

Usage
-----
This database is used to compile the elevation data within a user defined boundary. It is then overlayed with the compiled
OpenStreetMap greenspace and parking lot space geometries to rule out any locations that may be located on a incline gradient
above a certain threshold that would make GHE installation difficult. 

Data sources
------------
One can access various topographic data sources through OpenTopography and its APIs. For the purposes of this program,
we have utilized the NASA SRTMGL1 raster databse. This as a high resolution - 30 meter / 1 arc second
